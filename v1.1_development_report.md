# TopoStateGrid v1.1 Development Report

## Summary

- Added multi-source graph construction for pandapower `net` objects, pandas DataFrame tables, and CSV tables.
- pandapower support is implemented as an optional dependency and was validated with pandapower 3.4.0 in this environment.
- CSV/DataFrame support works and is covered with portable in-memory and temporary-file tests.
- Cross-source batching works for MATPOWER, DataFrame, CSV, and pandapower graphs in this environment. OPFData/MATPOWER mixed batching was already covered by the QA fix, and all sources share batch-safe metadata fields.
- Post-QA fixes updated environment documentation, documented matplotlib/numba warning behavior, and added a monkeypatch test for the pandapower missing-dependency branch.
- Added optional graph sequence rendering to GIF/MP4 through `render_graph_sequence`.
- Tests and examples pass. The pandapower example builds a real 3-bus graph when pandapower is installed and exits with a clear optional dependency message when pandapower is absent.

## New APIs

- `build_graph_from_pandapower`
- `build_graph_from_tables`

## Input Source Support

### OPFData JSON

Status: Supported from v1.0 and retained in v1.1.  
Tested: Existing examples and tests still pass; OPFData case14 local example builds `x=(14, 9)` and `edge_attr=(40, 12)`.  
Limitations: Local large OPFData folders remain ignored by git. No `.mat` support was added.

### MATPOWER / PGLib `.m`

Status: Supported from v1.0 and retained in v1.1.  
Tested: `data/pglib/pglib_opf_case118_ieee.m` builds a graph and participates in cross-source batching.  
Limitations: Static MATPOWER files do not provide solved operating-state flows unless supplied through another source.

### pandapower net object

Status: Implemented as optional dependency support.  
Tested / skipped: pandapower 3.4.0 is installed in this environment. The small pandapower unit network test passed, `examples/06_build_from_pandapower.py` built a 3-node/4-edge graph, and the missing-dependency branch is skipped while pandapower is installed.  
Limitations: `rate_a` for lines uses `max_i_ka` as an approximate rating proxy. Transformer parameters are mapped from available short-circuit/rating fields where possible, with unsupported values zero-filled.

### pandas DataFrame tables

Status: Implemented.  
Tested: Portable tests create 3-bus/2-branch DataFrames, validate shapes, feature names, metadata, finite tensors, state override behavior, zero-demand normalization, validation errors, and PyG batching.  
Limitations: Empty branch tables are rejected in v1.1. State tables with multiple timestamps require an explicit `timestamp`.

### CSV tables

Status: Implemented as a wrapper around pandas DataFrame support.  
Tested: Temporary CSV files are generated in tests and produce equivalent graph shapes, feature names, metadata, and state override behavior.  
Limitations: CSV parsing uses pandas defaults; large-scale optimized formats such as Parquet are not included in v1.1.

## Cross-Source Batching

The cross-source test batches MATPOWER, DataFrame, CSV, and pandapower graphs together with `torch_geometric.loader.DataLoader`. It succeeds with `batch.x.shape[1] == 9` and `batch.edge_attr.shape[1] == 12`.

Metadata batching is handled by keeping consistent top-level attributes on every graph:

- `network_id`
- `sample_id`
- `source_format`
- `timestamp`
- `scenario_id`
- `contingency_id`
- `metadata_json`

Source-specific metadata is stored as a JSON string instead of an arbitrary Python dictionary, and every graph initializes consistent label fields with `has_label` marking whether a real/proxy label is present.

## Visualization

Status: Implemented as optional dependency support.  
Tested: `examples/07_render_graph_animation.py` renders `outputs/topostategrid_sequence.gif` from a 5-frame table graph sequence.  
Limitations: Visualization inspects already constructed graph samples only; it does not simulate grid dynamics. GIF output uses matplotlib's Pillow writer. MP4 output requires ffmpeg.

## Remaining Limitations

- Homogeneous bus-branch graph only.
- No GNN model.
- No cascading-failure simulator.
- pandapower thermal rating mapping may be approximate because line `rate_a` uses `max_i_ka`.
- Visualization dependencies are optional; MP4 rendering requires ffmpeg, while GIF rendering requires matplotlib/networkx/Pillow.
- No `.mat` support.
- No heterogeneous graph support.
- No real cascading-failure labels.

1. Add `.mat` support if needed.
